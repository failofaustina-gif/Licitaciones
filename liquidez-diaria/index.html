Fuente y metodología

Fuente: Banco Central de la República Argentina (BCRA) — API oficial de estadísticas monetarias v4.0 (api.bcra.gob.ar/estadisticas/v4.0/monetarias). Los IDs marcados "No" en la columna "En frontend" se mantienen en el backend para reconstruir la identidad contable histórica y no se grafican por ahora.

ID 198 se conserva en el backend para el control analítico "Δ posición de operaciones de corto plazo del BCRA" (Δ ID198 = ID198(t) − ID198(t−1)), disponible de forma opcional y desactivada por defecto mediante el interruptor "Operaciones de corto plazo BCRA" sobre el primer gráfico. No se afirma que esta serie corresponda a compras/ventas de títulos, mercado secundario ni operaciones simultáneas. ID 70 se muestra como nivel (saldo) en la vista "Saldo (nivel)" del panel de cuentas corrientes; ID 63 se muestra como flujo diario en la vista "Variación (flujo)". Ambas vistas son alternativas del mismo panel y nunca se combinan ni se tratan como equivalentes.
